# RN Rice Mill Website

Responsive static website for RN Rice Mill, suitable for GitHub Pages.

## Files
- `index.html` — site structure and content
- `style.css` — responsive layout and design
- `script.js` — product information, search, quote list, mobile navigation, enquiry form

## Publish with GitHub Pages
1. Create a GitHub repository (for example `rn-rice-mill-website`).
2. Upload these files to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then Save.
6. Wait a few minutes and open the Pages URL GitHub provides.

## Before publishing
- Replace the sample phone number/email if needed.
- Review image URLs and replace with your own photos if preferred.
- The enquiry form uses `mailto:` and opens the visitor's email app. For a server-based form, connect a form service or backend.
